The \textbf{QConnectBase} package provides \textbf{Robot Framework} keywords for interacting with devices,
servers, or services through various communication protocols such as TCP/IP, SSH, or Serial.
It allows users to establish multiple connections, send commands, and easily verify responses.

\vspace{2ex}

\textbf{Key features}

\begin{itemize}
   \item Support for multiple simultaneous connections.
   \item Built-in keywords for sending and receiving data.
   \item Protocol abstraction for TCP/IP, SSH, and Serial.
   \item Flexible connection management and session handling.
   \item Extensible architecture for custom protocols or behaviors.
\end{itemize}

Developers can extend the \textbf{QConnectBase} code to support additional connection types or custom behaviors,
ensuring the library remains flexible and adaptable to diverse automation needs.

The sources of the \textbf{QConnectBase} are available in \href{https://github.com/test-fullautomation/robotframework-qconnect-base}{GitHub}.

Informations about how to install \textbf{QConnectBase} can be found in the \href{https://github.com/test-fullautomation/robotframework-qconnect-base/blob/develop/README.rst}{README}.
